## ✅ Template Format Dokumen Setiap Modul (Sama kaya Travel Expense)

Setiap dokumen detail modul nanti akan distandardisasi struktur:

```
1. Overview + File Codebase References (with line klik)
2. Role Matrix 7×N (siapa bisa aksi apa ✅❌ table)
3. Entities & Data Model (5 Tables+) + Relation Diagram ASCII
4. State Machine (semua status + trigger method yang mengubah status)
5. Use Case End-to-End (contoh nominal riil + flow langkah demi langkah)
6. Zod DTO Validator List (required field + rules)
7. Semua API Endpoints (Method + Route + Middleware + Deskripsi)
8. Integration Antar-Modul (data flow ke modul lain + kapan trigger)
9. 5-6 Business Rules Gap (validasi yang masih manual, harus di-hardening ke service layer)
10. TL;DR Flowchart Ringkas (30 detik paham)
```
